Privacy Policy

Last updated: 2026-04-19

TL;DR. ClaudeBell is free, open source (MIT), and runs entirely on your Mac. No telemetry, no analytics, no accounts. The only outbound requests it makes are to check for updates from claude-bell.com.

This Privacy Policy describes how the ClaudeBell macOS application (the "Software") and the website claude-bell.com (the "Website") handle information.

1. What ClaudeBell does locally

Everything the Software does with your data happens on your Mac:

  • Claude Code hook events (permission prompts, notifications, tool errors, session lifecycle) are received by a local HTTP server bound to localhost:19485 and never leave your machine.
  • Conversation transcripts, prompts, tool outputs, and file paths are read only from your local Claude Code state directory (~/.claude/) and displayed inside the app. They are never transmitted anywhere.
  • App preferences, notification sounds, hook installation state, and auto-mode settings are stored locally in macOS user defaults or in the Claude Code settings file.

2. What ClaudeBell sends over the network

The Software makes update checks to claude-bell.com to fetch the changelog and, if you choose to update, download the new version. Standard HTTP headers (IP address, user agent, ClaudeBell version) are sent; no user-identifying data. No analytics SDKs, no crash reporters, no advertising networks, no trackers.

3. What the Website collects

The Website is a static landing page hosted on Vercel. Vercel processes standard server access logs (IP address, user agent, request path, timestamp) for security and operational purposes under Vercel's own privacy policy. The Website sets no cookies and uses no analytics trackers.

4. Donations

If you choose to support the project via Buy Me a Coffee, that transaction is handled entirely by Buy Me a Coffee under their privacy policy. We do not receive or store your payment details.

5. Source code and contributions

ClaudeBell is open source under the MIT License. If you file an issue or submit a pull request on GitHub, that information is governed by GitHub's privacy policy.

6. Contact

Questions about this policy: support@claude-bell.com.
